# Store photos

The homepage "Magazinul fizic" section shows 2 photos of the physical shop.

Drop the owner's photos here as:

- `interior-1.jpg`
- `interior-2.jpg`

They'll appear on the homepage automatically — no code changes needed. Until
they're here, the homepage shows a placeholder instead of a broken image.

Recommended: landscape orientation, roughly 1600x1200px, under ~400KB each.
